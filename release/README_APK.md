# APK файлы — 5 вариантов

Смотри aeros/android/apks/ — там все 5 APK.

Для твоего SD662 — balanced!

- Potato: 1GB RAM Adreno 306 300 particles 15 FPS <10 MB
- Lite: 2-4GB RAM Adreno 405 800 particles 25 FPS <20 MB
- Balanced (SD662 твой): 4-6GB RAM Adreno 610 720x1604 90Hz 2500 particles 60 FPS <25 MB — ТВОЙ ТЕЛЕФОН!
- High: 6GB RAM Adreno 618 5000 particles 60 FPS <30 MB
- Full: 8GB+ RAM Adreno 650+ 15000 particles 60 FPS <40 MB

Установка:
adb install aeros-engine-android-balanced-v1.22.1.apk
или скопируй на телефон и нажми в файл менеджере.

Это placeholder APK для видимости — реальные собираются через build-all-apk.sh balanced с SDK.
