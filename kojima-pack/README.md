# KOJIMA PACK — анимации по мотивам MGS и Death Stranding

Фанатский проект для **Minecraft Java Edition 1.21.11**: настоящие анимации
в духе Хидео Кодзимы — CQC-стойка, крадущийся с коробкой, баланс Сэма
под грузом, MGS-алерт `!` над головой и Фултон в небо.

> Статус: **v0.3 — MC 1.21.11, эмоуты переведены на `.json` (фикс для
> Emotecraft 3.x), BB-капсула и хиральная рука перерисованы**.
> Паки зафиксированы на формат 1.21.11 (ресурсы — 75, данные — 94.1).

---

## 1. Установка

### Эмоуты (нужен мод Emotecraft 3.x)
1. Поставь **на MC 1.21.11** с Modrinth (вкладка Versions, build 163):
   - **Emotecraft** `3.2.0-b.build.163` под свой загрузчик
     (`emotecraft-fabric-for-MC1.21.11-...` или `...-neoforge-...`);
   - **Player Animation Library** (обязательная зависимость, тот же MC/загрузчик);
   - **Fabric API** (только для Fabric).
   Все три jar — в папку `mods/`.
2. Скопируй `.json`-файлы из папки `emotes/` в папку эмоутов.
   Где она: в игре открой настройки мода Emotecraft → кнопка
   **«Open emotes folder»** (у Prism/Modrinth-App это папка инстанса,
   НЕ `%appdata%/.minecraft`!). Перезапусти игру.
3. Нажми **B** — колесо эмоутов. Выбирай и играй.

> ⚠️ Почему именно `.json`: в Emotecraft 3.x расширение `.emotecraft`
> читает **бинарный** ридер, а JSON-эмоуты (включая классический формат)
> грузятся только из `.json` — проверено по исходникам мода
> (`UniversalEmoteSerializer` + встроенные эмоуты). Для старого Emotecraft 2.x
> наши файлы тоже подойдут — переименуй их обратно в `.emotecraft`.

### Датапак с анимациями (без модов)
1. Скопируй папку `datapack/` в `<мир>/datapacks/` под именем `kojima`.
2. В игре выполни `/reload` — в чат придёт подтверждение загрузки.
3. Триггеры (команда `/trigger` доступна даже без прав OP):
   - `/trigger kj_go set 1` — **Фултон**: шар уносит тебя в небо, спуск плавный;
   - `/trigger kj_go set 2` — тест **MGS-алерта** (красный `!` + стингер);
   - `/trigger kj_go set 3` — чистка всех эффектов пака.
4. Автоматика: **получил урон = засекли** — над головой сам всплывает `!`
   (кулдаун 3 секунды, чтобы не спамило).

### Ресурспак (бонус: текстуры)
1. Собери zip: `bash tools/build_zip.sh` (или зазипуй *содержимое* папки
   `resourcepack/` — не саму папку!).
2. Положи zip в `.minecraft/resourcepacks/` (или в папку инстанса).
3. Включи в Настройки → Ресурспаки. Проверка:
   `/give @s minecraft:totem_of_undying` — янтарная BB-капсула с пузырьком.

### Если эмоуты не появились — чеклист
1. Одиночная игра? (На ванильном сервере мод неактивен — нужен мод и на
   сервере, либо мод `online-emotes`.)
2. Папка точно та? (Кнопка «Open emotes folder» в настройках мода.)
3. Игра перезапущена после копирования файлов?
4. В `mods/` лежат все три: Emotecraft + PlayerAnimLib + Fabric API
   (для Fabric), все под 1.21.11?
5. В `logs/latest.log` есть строки с `emotes`/`emotefcraft` об ошибках?
   Пришли их — разберём.

## 2. Анимации

### A. Emotecraft-эмоуты (`emotes/*.json`) — скелетные, видят все с модом

| Файл | Анимация | Длина |
|---|---|---|
| `cqc_guard.json` | **CQC-стойка**: низкая guard-поза, покачивание, голова сканирует стороны | 3.0 c |
| `box_sneak.json` | **Крадущийся с коробкой**: глубокий sneak, руки держат коробку, перевалка | 4.0 c |
| `porter_balance.json` | **Баланс Сэма**: руки широко, тяжёлая качка под грузом из стороны в сторону | 3.8 c |

Формат — классический KosmX JSON (`moves` + `pitch/yaw/roll`, `degrees: true`,
20 тиков = 1 секунда), заголовок (`name`/`author`/`description` — компоненты,
`uuid`, `previewTick`) — один в один как у встроенных эмоутов мода.
Файлы можно открыть и докрутить в Blockbench/Blender.

### B. Датапак (`datapack/`) — ванильные анимации, модов не надо

| Функция | Что происходит |
|---|---|
| `kojima:alert` | Красный `!` (text_display) с pop-анимацией масштаба 0.05→1.5 за 5 тиков + стингер из нотных блоков (3 доли через `schedule`) + плавное схлопывание |
| `kojima:fulton` | Шар (block_display, едет на игроке через `/ride`) + левитация 4 c + облачка `cloud` каждый тик + лопанье (`poof`) и плавный спуск (`slow_falling`) |
| `kojima:tick` | Детект урона через скорборд `damage_taken`, кулдауны, триггеры `/trigger kj_go` |

Приёмы, которые тут используются (это и есть «ванильные анимации»):
- `interpolation_duration` + `transformation.scale` у display-сущностей;
- `schedule function` для цепочек во времени (pop → держать → схлопнуть);
- `/ride`, чтобы декор следовал за игроком;
- скорборды `damage_taken` / `trigger` как кнопки запуска.

Ограничения демо (честно): scheduled-функции теряют контекст игрока, поэтому
мультиплеер-гонки решаются тегами (`kj_beat`, `kj_fly`) — на сервере с онлайном
`!` и шары общие на всех. Для продакшена каждому эффекту нужен свой ID.

| Файл | Что это |
|---|---|
| `textures/item/totem_of_undying.png` (+`.mcmeta`) | **BB-капсула**: янтарный купол, младенец, корпус с синей лампой; 4 кадра — пузырёк всплывает, лампа статуса зелёный→красный |

датапак `min: [94, 1], max: 94` (новый синтаксис 1.21.9+, без `pack_format`).

## 5. Звуки (когда дойдёшь)

1. Положи Ogg Vorbis (44100 Hz) в `assets/minecraft/sounds/kojima/`.
2. Переименуй `sounds.json.example` → `sounds.json`.
3. Добавь субтитры в `lang/*.json`.
4. Проверка: `/playsound kojima.alert hostile @s`.

Звуки — только свои/лицензионные (синтез, Audacity, CC0-библиотеки).
**Не выдирай .ogg из игр Konami/Sony** — иначе пак не примут на
CurseForge/Modrinth/PlanetMinecraft.
