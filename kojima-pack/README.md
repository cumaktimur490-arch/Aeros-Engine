# KOJIMA PACK — анимации по мотивам MGS и Death Stranding

Фанатский проект для **Minecraft Java Edition**: настоящие анимации в духе
Хидео Кодзимы — CQC-стойка, крадущийся с коробкой, баланс Сэма под грузом,
MGS-алерт `!` над головой и Фултон в небо.

> Статус: **v0.2 — упор на анимации**.
> Два трека: **Emotecraft-эмоуты** (скелетные анимации игрока) и **ванильный
> датапак** (алерт + фултон без модов). Ресурспак с текстурами — приятный бонус.

---

## 1. Установка

### Эмоуты (Emotecraft, нужен мод)
1. Поставь мод **Emotecraft** с Modrinth/CurseForge (есть под Fabric/Forge/Quilt).
2. Скопируй файлы из папки `emotes/` в `.minecraft/emotes/`.
3. В игре открой меню эмоутов (клавиша настраивается в
   Настройки → Управление → Emotecraft) и выбери эмоут.

### Датапак с анимациями (без модов)
1. Скопируй папку `demo-datapack/` в `<мир>/datapacks/` под именем `kojima`.
2. В игре выполни `/reload` — в чат придёт подтверждение загрузки.
3. Триггеры (команда `/trigger` доступна даже без прав OP):
   - `/trigger kj_go set 1` — **Фултон**: шар уносит тебя в небо, спуск плавный;
   - `/trigger kj_go set 2` — тест **MGS-алерта** (красный `!` + стингер);
   - `/trigger kj_go set 3` — чистка всех эффектов пака.
4. Автоматика: **получил урон = засекли** — над головой сам всплывает `!`
   (кулдаун 3 секунды, чтобы не спамило).

### Ресурспак (бонус: текстуры)
1. Собери zip: `bash tools/build_zip.sh` (или зазипуй *содержимое* папки
   `resourcepack/` — не саму папку!).
2. Положи `KOJIMA-PACK-v0.1.zip` в `.minecraft/resourcepacks/`.
3. Включи в Настройки → Ресурспаки.

## 2. Анимации

### A. Emotecraft-эмоуты (`emotes/`) — скелетные, видят все с модом

| Файл | Анимация | Длина |
|---|---|---|
| `cqc_guard.emotecraft` | **CQC-стойка**: низкая guard-поза, покачивание, голова сканирует стороны | 3.0 c |
| `box_sneak.emotecraft` | **Крадущийся с коробкой**: глубокий sneak, руки держат коробку, перевалка | 4.0 c |
| `porter_balance.emotecraft` | **Баланс Сэма**: руки широко, тяжёлая качка под грузом из стороны в сторону | 3.8 c |

Файлы написаны руками в формате Emotecraft (`moves` + `pitch/yaw/roll`,
`degrees: true`, 20 тиков = 1 секунда). Их же можно открыть и докрутить
в Blockbench (плагин Emotecraft) — структура совместима.
Как писать свои: начни с нейтральной позы на тике 0, ставь ключевой кадр
на каждую смену позы, в конце обязательно возвращайся в нейтраль —
иначе будет рывок при завершении.

### B. Датапак (`demo-datapack/`) — ванильные анимации, модов не надо

| Функция | Что происходит |
|---|---|
| `kojima:alert` | Красный `!` (text_display) с pop-анимацией масштаба 0.05→1.5 за 5 тиков + стингер из нотных блоков (3 доли через `schedule`) + плавное схлопывание |
| `kojima:fulton` | Шар (block_display, едет на игроке через `/ride`) + левитация 4 c + облачка `cloud` каждый тик + лопанье (`poof`) и плавный спуск (`slow_falling`) |
| `kojima:tick` | Детект урона через скорборд `damage_taken`, кулдауны, триггеры `/trigger kj_go` |

Приёмы, которые тут используются (это и есть «ванильные анимации»):
- `interpolation_duration` + `transformation.scale` у display-сущностей;
- `schedule function` для цепочек во времени (pop → держать → схлопнуть);
- `/ride`, чтобы декор следовал за игроком;
- скорборды `damage_taken` / `trigger` как кнопки запуска.

Ограничения демо (честно): scheduled-функции теряют контекст игрока, поэтому
мультиплеер-гонки решаются тегами (`kj_beat`, `kj_fly`) — на сервере с онлайном
`!` и шары общие на всех. Для продакшена каждому эффекту нужен свой ID —
это следующий шаг (см. Roadmap).

## 5. Звуки (когда дойдёшь)

1. Положи Ogg Vorbis (44100 Hz) в `assets/minecraft/sounds/kojima/`.
2. Переименуй `sounds.json.example` → `sounds.json`.
3. Добавь субтитры в `lang/*.json`.
4. Проверка: `/playsound kojima.alert hostile @s`.

Звуки — только свои/лицензионные (синтез, Audacity, CC0-библиотеки).
**Не выдирай .ogg из игр Konami/Sony** — иначе пак не примут на
CurseForge/Modrinth/PlanetMinecraft.
