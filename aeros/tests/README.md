# Headless-тесты Aeros Engine

Тесты, которые проверяют логику движка **без OpenGL, GLFW и CUDA** — их можно
запустить в любом Linux-контейнере и в CI, где нет графики.

| Файл | Что проверяет |
|---|---|
| `timelapse_headless.cpp` | Режим вычислений (v1.26.0): кольцевой буфер истории, переполнение и счётчик перезаписанных кадров, поиск кадра по номеру, снимки поля давления и отказ отдавать затёртый снимок, скорость и цикл воспроизведения, заморозка буфера во время просмотра, экспорт CSV (число строк, заголовок и **совпадение числа полей в строке данных с заголовком** — 47 колонок с v1.29.0), сводка для отладочного отчёта (включая статистику такта физики), смена ёмкости, фоновая запись. 43 проверки. |
| `lbm_physics_headless.cpp` | Решатель LBM (v1.27.0 → v1.30.0) на синтетическом обтекании сферы: сохранение массы (\|ρ−1\| < 0.02), отсутствие отрицательных и заменённых популяций, физический диапазон TKE (м²/с²), физичность максимальной скорости, влияние модели Смагоринского на результат, гладкость трилинейной выборки давления и честное «нет данных» вне расчётной области. **v1.30.0 — разделы на исправленные ошибки физики:** вязкость по Сазерленду (контрольные точки 273.15 K → ровно 1.716e-5 Па·с, 288.15 K → 1.789e-5, монотонность, защита от передачи °C и NaN) и сквозная сверка `lbmReynolds = ρ·V·L/μ(T[K])` на уровне моря и на 5000 м; сохранение массы и импульса равновесных популяций при ρ = 0.55…1.6 (включая регрессию «ρ=1.35 не подменяется на 1.2»); явный источник поля скорости во всех четырёх состояниях (тело / домен LBM / вне домена / LBM выключен); неизменность TKE после `computeLBMVorticityAndQ()` при пересчитанном вихре и Q-критерии; список настроек без эффекта и равенство решения с включёнными и выключенными MRT/Zou-He/регуляризацией. Проверка «давление ограничено скоростным напором (Cp ∈ [−2, 2])» **удалена** — она защищала искусственную обрезку физического поля; вместо неё конечность, наличие разрежения и подпора, отсутствие ячеек на потолке ±q и линейность `p(ρ)` одним коэффициентом. **80 проверок.** |
| `phys_clock_headless.cpp` | Фиксированный такт физики (v1.29.0): число тактов = frameDt·hz, то есть частота физики не зависит от герцовки монитора (30/60/144/1000 к/с дают одинаковое модельное время); шаги решётки LBM считаются по модельному времени, а дробный остаток переносится без дрейфа; защита от спирали смерти (предел тактов, обрезка длинного кадра) и честный учёт пропущенного реального времени (`droppedTime`, `wallScale`); мусор на входе (NaN, inf, отрицательный dt, hz=0/1e9) не ломает арифметику; обратная совместимость покадрового режима; монотонность и `reset()`. 67 проверок. |

Запуск:

```bash
cd aeros/tests
make             # все три теста
make timelapse   # только таймлапс
make lbm         # только прогон решателя
make physclock   # только такт физики
```

Все тесты возвращают код 0 при успехе и 1 при любом провале, поэтому их можно
встраивать в CI.

Тесты намеренно **не входят** ни в один релизный сборочный скрипт: вместо
OpenGL/GLFW/CUDA они линкуют заглушки (`updateVertexColors`, `computeLiftDrag`,
`glfwGetTime`, `setVoxelData`, `cudaConsumeError`), поэтому проверяют физику и
логику, но не отрисовку.

Опорные значения прогона LBM (сфера R = 0.7 м, V∞ = 20 м/с, сетка 24³, 120 шагов):
ρ ≈ 0.9935, Cp на критической точке ≈ +1.00 (теоретическое значение для
несжимаемого обтекания), vmax ≈ 1.13·V∞, TKE ≈ 3.9·10⁻² м²/с², отрицательных
популяций 0.
