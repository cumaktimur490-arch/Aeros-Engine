# Headless-тесты Aeros Engine

Тесты, которые проверяют логику движка **без OpenGL, GLFW и CUDA** — их можно
запустить в любом Linux-контейнере и в CI, где нет графики.

| Файл | Что проверяет |
|---|---|
| `timelapse_headless.cpp` | Режим вычислений (v1.26.0): кольцевой буфер истории, переполнение и счётчик перезаписанных кадров, поиск кадра по номеру, снимки поля давления и отказ отдавать затёртый снимок, скорость и цикл воспроизведения, заморозка буфера во время просмотра, экспорт CSV (число строк и заголовок), сводка для отладочного отчёта, смена ёмкости, фоновая запись. 40 проверок. |
| `lbm_physics_headless.cpp` | Решатель LBM (v1.27.0) на синтетическом обтекании сферы: сохранение массы (\|ρ−1\| < 0.02), отсутствие отрицательных и заменённых популяций, физический диапазон TKE (м²/с²), ограничение давления скоростным напором (Cp ∈ [−2, 2]), физичность максимальной скорости, влияние модели Смагоринского на результат, гладкость трилинейной выборки давления и честное «нет данных» вне расчётной области. 11 проверок. |

Запуск:

```bash
cd aeros/tests
make            # оба теста
make timelapse  # только таймлапс
make lbm        # только прогон решателя
```

Оба теста возвращают код 0 при успехе и 1 при любом провале, поэтому их можно
встраивать в CI.

Тесты намеренно **не входят** ни в один релизный сборочный скрипт: вместо
OpenGL/GLFW/CUDA они линкуют заглушки (`updateVertexColors`, `computeLiftDrag`,
`glfwGetTime`, `setVoxelData`, `cudaConsumeError`), поэтому проверяют физику и
логику, но не отрисовку.

Опорные значения прогона LBM (сфера R = 0.7 м, V∞ = 20 м/с, сетка 24³, 120 шагов):
ρ ≈ 0.9935, Cp на критической точке ≈ +1.00 (теоретическое значение для
несжимаемого обтекания), vmax ≈ 1.13·V∞, TKE ≈ 3.9·10⁻² м²/с², отрицательных
популяций 0.
