# Лицензия glad

Каталог `libs/glad` содержит код, сгенерированный генератором **glad 0.1.36**
(команда генерации записана в шапке `include/glad/glad.h`).

## Генератор glad и загрузчик

glad распространяется по лицензии MIT. Полный официальный текст —
[`LICENSES/MIT.txt`](LICENSES/MIT.txt).

## Объявления OpenGL API

Типы и константы OpenGL получены из спецификации Khronos `gl.xml` и
распространяются по лицензии Apache-2.0. Полный официальный текст —
[`LICENSES/Apache-2.0.txt`](LICENSES/Apache-2.0.txt).

Оба текста взяты из официального репозитория Khronos Vulkan-Headers
(`LICENSES/`) без изменений; они идентичны текстам, которые Khronos публикует
для `gl.xml` и `glcorearb.h`.
